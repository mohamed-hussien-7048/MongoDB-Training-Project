# MongoDB-Training-Project

## فكرة المشروع

تطبيق ويب لإدارة الأشخاص والأرصدة، من خلال واجهة تقدر تستخدمها لإضافة الأشخاص وعرض بياناتهم وتعديلها أو حذفها.

المشروع معمول باستخدام **Node.js وExpress** مع **MongoDB**، وبيستخدم **Mongoose** لتنظيم التعامل مع البيانات داخل قاعدة البيانات.

---

## أهم مميزات المشروع

- إضافة شخص جديد بالاسم والرصيد.
- عرض بيانات الأشخاص المسجلين.
- تعديل بيانات شخص أو حذفه.
- عرض إحصائيات عدد الأشخاص وإجمالي ومتوسط الأرصدة.
- التحقق من بعض قواعد البيانات، زي إن الاسم مطلوب والرصيد ما يكونش سالب.

---

## التقنيات المستخدمة

- **Node.js:** تشغيل التطبيق على السيرفر.
- **Express.js:** إنشاء API والتعامل مع طلبات الواجهة.
- **MongoDB:** تخزين بيانات الأشخاص.
- **Mongoose:** تعريف شكل البيانات والتعامل معاها.
- **dotenv:** حفظ إعدادات التشغيل في ملف البيئة.
- **HTML, CSS & JavaScript:** بناء واجهة المستخدم.

---

## تشغيل المشروع

1. ثبّت الحزم المطلوبة باستخدام `npm install`.
2. تأكد إن MongoDB شغّال.
3. راجع رابط قاعدة البيانات في ملف `.env`.
4. شغّل السيرفر باستخدام أمر التشغيل الموجود في `package.json`.
5. افتح الواجهة من خلال السيرفر.
